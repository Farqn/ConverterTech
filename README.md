# ⚡ ConverterTech

**ConverterTech**, modern web standartları gözetilerek geliştirilmiş, hızlı, pratik ve kullanıcı dostu bir çevirici/dönüştürücü web aracıdır.

## 🚀 Özellikler

* **Hızlı ve Hafif:** Ekstra kütüphane yükü olmadan, saf ve optimize edilmiş yapıyla anında çalışır.
* **Modern Arayüz:** Göz yormayan, şık ve minimalist koyu tema tasarımı.
* **Kullanıcı Dostu:** Karmaşık menülerden uzak, doğrudan sonuca ulaştıran pratik kullanım.
* **Tek Dosya / Modüler Yapı:** Kolayca özelleştirilebilir ve dağıtılabilir altyapı.

---

## 🛠️ Kullanılan Teknolojiler

Projede geliştirme sürecinde tercih edilen temel teknolojiler:
* **HTML5** / **CSS3** (Modern Flexbox/Grid düzenleri, özel tasarım bileşenleri)
* **JavaScript (ES6+)** (Dinamik işlemler ve arayüz yönetimi)
